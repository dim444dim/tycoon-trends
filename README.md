# Tycoon Trends

Jeu Roblox de type tycoon idle avec un système de **tendances** : certains bâtiments bénéficient d'un bonus ×2 en rotation, forçant les joueurs à adapter leur stratégie en temps réel.

## Stack

- Roblox Studio
- Rojo 7.4.4 (sync VSCode ↔ Studio)
- Aftman (gestion toolchain)
- Luau

## Démarrage rapide

```bash
aftman install
rojo serve
# Puis connecter le plugin Rojo dans Studio
```
